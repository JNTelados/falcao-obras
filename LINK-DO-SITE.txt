COMO COLOCAR O SITE NO AR NOVAMENTE
-----------------------------------
Abra o PowerShell na pasta do projeto e rode:

  cd C:\rea\falcao-site
  pnpm build
  pnpm start

Para gerar um NOVO link publico (o anterior muda a cada reinicio):

  C:\rea\falcao-site\tools\cloudflared.exe tunnel --url http://localhost:3210

O link novo aparece no meio das mensagens, procure a linha parecida com:
  |  https://algum-nome-aleatorio.trycloudflare.com  |


LIBERAR O ACESSO PELO WI-FI LOCAL (opcional)
--------------------------------------------
Precisa de permissao de administrador:

  1. Duplo clique em:  abrir-para-celular.bat
  2. Clique em "Sim" na janela do Windows

Ou, no PowerShell como Administrador:

  New-NetFirewallRule -DisplayName "Falcao Site 3210 (TCP-In)" -Direction Inbound -Protocol TCP -LocalPort 3210 -Action Allow -Profile Private


OBSERVACOES
-----------
- O link trycloudflare e temporario: cai quando o tunel ou o servidor param.
- Qualquer pessoa com o link consegue ver o site (nao tem palavra-passe).
- Para um endereco fixo e definitivo, publique em Netlify ou Vercel.
