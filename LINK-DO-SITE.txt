FALCAO OBRAS & REMODELACOES
===========================

DOMINIO PROPRIO:  https://www.falcaoobras.pt
(comprado na one.com - veja o passo a passo em DOMINIO.md)

CODIGO NO GITHUB:
  https://github.com/JNTelados/falcao-obras


PARA O SITE FICAR NO AR (falta este passo - 2 minutos)
------------------------------------------------------
  1. Abra: https://app.netlify.com/start/deploy?repository=https://github.com/JNTelados/falcao-obras
  2. Entre com a conta GitHub e autorize
  3. Confirme: build "pnpm build:static" | publish "out"
  4. Clique em Deploy
  5. Depois ligue o dominio (passo a passo em DOMINIO.md)


GUIAS
-----
  DOMINIO.md    -> ligar falcaoobras.pt a Netlify (DNS da one.com explicado)
  PUBLICAR.md   -> como publicar e atualizar o site (guia geral)
  README.md     -> como o projeto esta organizado


NO SEU COMPUTADOR
-----------------
  cd C:\rea\falcao-site
  pnpm dev              -> http://localhost:3210
  pnpm build:static     -> gera a pasta out pronta a publicar
  node scripts\verificar-dominio.mjs falcaoobras.pt   -> checa o DNS


VERIFICAR SE O DOMINIO JA PROPAGOU
----------------------------------
  node scripts\verificar-dominio.mjs falcaoobras.pt
  (deve mostrar os IPs da Netlify: 75.2.60.5 e 99.83.190.102)
